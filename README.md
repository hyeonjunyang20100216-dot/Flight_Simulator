# Flight_Simulator
Large Map Flight Simulator

브라우저에서 바로 실행되는 3D 비행 시뮬레이터입니다 (Three.js, 단일 `index.html`).

## 실행
`index.html`을 최신 데스크톱 브라우저(Chrome 등)에서 열면 됩니다. 인터넷 연결이 필요합니다 (Three.js를 CDN에서 불러옴).

## 조작
| 키 | 동작 |
|---|---|
| W / S | 피치 (기수 내리기 / 올리기) |
| A / D | 롤 (좌 / 우) |
| Q / E | 러더 (요) |
| Shift / Ctrl (또는 Z / X) | 스로틀 증가 / 감소 |
| Space (또는 B) | 휠 브레이크 |
| G | 랜딩기어 |
| F | 플랩 (0 / 1 / 2 / LDG) |
| C / V | 카메라 전환 / 조종석 시점 |
| N | 목적지 공항 전환 |
| + / - | 미니맵 확대 / 축소 |
| R | 리셋 |
| Esc | 일시정지 |
| 마우스 | 카메라 둘러보기 |

## 특징
- 기종 3종: 경비행기, 여객기(협동체 쌍발), 전투기 — 각각 다른 모델과 물리
- 공항 3곳: Central International, Coast Airport, Highland Regional
- 대형 맵: 산, 강, 호수, 해안, 도시, 마을, 숲, 농경지, 도로
- 낮/밤, 날씨(맑음~폭풍), 바람, 구름, 착륙 결과 통계
